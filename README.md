# عُدّة المهندس

موقع عربي مجاني ثابت يضم أدوات هندسية لطلاب الهندسة والفنيين، مع حل خطوة بخطوة لكل أداة.

## المبادئ

- HTML و CSS و JavaScript فقط، بلا خادم ولا قاعدة بيانات ولا خطوة بناء.
- بلا حسابات ولا كوكيز ولا تحليلات.
- كل الروابط نسبية، فيعمل الموقع من أي مسار فرعي مثل `/repo-name/` على GitHub Pages.
- المكتبات الخارجية منسوخة محلياً في `vendor/` بإصدارات مثبتة.

## هيكل المشروع

| المسار | المحتوى |
|---|---|
| `index.html` | الصفحة الرئيسية مع البحث في كل الأدوات |
| `category/<التصنيف>/` | صفحة لكل تصنيف |
| `tools/<الأداة>/` | صفحة لكل أداة |
| `assets/css/` | التنسيقات المشتركة |
| `assets/js/` | دوال الواجهة المشتركة وسجل الأدوات `registry.js` |
| `lib/` | وحدات الحساب الصافية (ES modules بلا DOM)، تستخدمها الصفحات والاختبارات |
| `vendor/` | المكتبات الخارجية المثبتة |
| `tests/unit/` | اختبارات الوحدات بـ node:test |
| `tests/browser/` | اختبارات المتصفح بـ Playwright |
| `tests/site/` | فحص الروابط و SEO والعمل من مسار فرعي |
| `scripts/` | خادم محلي ومولّد sitemap |
| `site.config.json` | اسم الموقع والنطاق وإعدادات الإعلانات (معطلة) |

## التشغيل محلياً

```bash
npm install
npm run serve
```

ثم افتح `http://localhost:8080/`. ولتجربة المسار الفرعي كما في GitHub Pages:

```bash
node scripts/serve.mjs --base /test-repo/
```

## توليد الصفحات

صفحات HTML تُكتب مسبقاً من `assets/js/registry.js` وبيانات `meta` في كل وحدة داخل `lib/`. بعد أي تعديل:

```bash
npm run generate
```

الملفات الناتجة تُحفظ في المستودع، فالموقع يعمل كما هو بلا خطوة بناء عند النشر.

## الاختبارات

```bash
npm test
```

يشغّل بالترتيب:
- `npm run test:unit`: اختبارات الوحدات والتحققات المستقلة.
- `npm run test:site`: فحص الروابط و SEO والمسار الفرعي.
- `npm run test:browser`: اختبارات Playwright على Chrome المثبت، بعرض الهاتف والحاسوب، مع لقطات شاشة في `tests/screenshots/`.
