علوم الحاسوب والشبكات

الشبكات الفرعية وعناوين IP وتمثيل الأعداد العشرية IEEE-754 والترميز وتعقيد الخوارزميات وأحجام البيانات وزمن النقل.

  • حاسبة الشبكات الفرعية IPv4احسب تفاصيل شبكة IPv4 من العنوان والقناع: عنوان الشبكة والبث وأول وآخر مضيف وعدد المضيفين والقناع العكسي والفئة، مع التمثيل الثنائي وتقسيم الشبكة إلى شبكات فرعية.
  • تمثيل الأعداد العشرية IEEE-754حوّل أي عدد عشري إلى تمثيله بمعيار IEEE-754 بدقة مفردة (32 بت) أو مزدوجة (64 بت): بت الإشارة والأس المنحاز والجزء الكسري والقيمة الست عشرية، والقيمة المخزنة فعلاً وخطأ التقريب، والعكس.
  • الترميز: ASCII و UTF-8 و Base64حوّل النص إلى نقاط ترميز Unicode وبايتات UTF-8 بالست عشري والثنائي وBase64 وترميز URL، أو فك شيفرة Base64 والست عشري إلى نص، مع جدول تفصيلي لكل حرف.
  • مقارنة تعقيد الخوارزمياتقارن عدد العمليات والزمن التقريبي لأصناف التعقيد O(1) وO(log n) وO(n) وO(n log n) وO(n²) وO(n³) وO(2ⁿ) وO(n!) لحجم مدخلات وسرعة تنفيذ معيّنين، مع رسم بياني لمقارنة النمو.
  • أحجام البيانات وزمن النقلاحسب زمن نقل ملف بحجم وسرعة معيّنين مع نسبة فاقد البروتوكول، وحوّل الحجم إلى كل الوحدات العشرية والثنائية، مع توضيح الفرق بين البايت والبت وبين MB وMiB.
