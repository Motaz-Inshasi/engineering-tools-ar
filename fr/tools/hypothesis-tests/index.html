Tests d'hypothèses

Effectuez les tests d'hypothèses courants : z et t pour un échantillon, pour deux échantillons et pour des paires, test de proportions, et khi-deux d'adéquation et d'indépendance, avec la statistique de test, la valeur p, la valeur critique, la décision et l'intervalle de confiance.

📘 Formule utilisée

Cliquer pour afficher
Statistique t pour un échantillon
t=xˉ−μ0s/n,df=n−1t = \frac{\bar x - \mu_0}{s/\sqrt n},\quad df = n - 1t=s/n​xˉ−μ0​​,df=n−1

✏️ Données d'entrée

Laissez vide pour supposer l'égalité. Vous pouvez saisir des proportions comme 0.25 0.5 0.25 ou des effectifs.

Exemple : un échantillon de 25 étudiants a une moyenne de 52.3 et un écart type de 6.1 ; la moyenne diffère-t-elle de 50 ?
