الحل العددي للمعادلات التفاضلية (أويلر ورونغ-كوتا)

حل أي معادلة تفاضلية من الرتبة الأولى y′ = f(x, y) عددياً بطرق أويلر وهيون (أويلر المحسّنة) ورونغ-كوتا الرابعة، مع جدول الخطوات والمقارنة بين الطرق والحل الدقيق إن وُجد، والرسم.

📘 القانون المستخدم

اضغط للعرض
أويلر
yn+1=yn+h f(xn,yn)y_{n+1} = y_n + h\,f(x_n, y_n)yn+1​=yn​+hf(xn​,yn​)
رونغ-كوتا الرابعة
yn+1=yn+h6(k1+2k2+2k3+k4)y_{n+1} = y_n + \frac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4)yn+1​=yn​+6h​(k1​+2k2​+2k3​+k4​)

✏️ المدخلات

استخدم x و y، مثل x*y أو -2*y + sin(x) أو y*(1 - y).
دالة في x فقط، لحساب الخطأ.

مثال: y′ = x + y مع y(0) = 1، وحلها الدقيق 2eˣ − x − 1.

⚡ يتحدّث الناتج تلقائياً عند تعديل المدخلات
