حاسبة الطور (Phasor)

حاسبة الطور (Phasor): اجمع أو اطرح أو اضرب أو اقسم إشارتين جيبيتين بالصيغة القطبية أو الديكارتية، وحوّل الناتج إلى الصيغة الزمنية v(t)، مع مخطط الطور ورسم الموجات.

القوانين المستخدمة

التحويل بين الزمن والطور
v(t)=Vmcos⁡(ωt+ϕ)  ↔  V=Vm∠ϕv(t) = V_m\cos(\omega t + \phi) \;\leftrightarrow\; \mathbf{V} = V_m\angle\phiv(t)=Vm​cos(ωt+ϕ)↔V=Vm​∠ϕ
الجمع ديكارتياً والضرب قطبياً
V1+V2=(a1+a2)+j(b1+b2),V1V2=V1V2∠(ϕ1+ϕ2)\mathbf{V}_1 + \mathbf{V}_2 = (a_1+a_2) + j(b_1+b_2),\qquad \mathbf{V}_1\mathbf{V}_2 = V_1V_2\angle(\phi_1+\phi_2)V1​+V2​=(a1​+a2​)+j(b1​+b2​),V1​V2​=V1​V2​∠(ϕ1​+ϕ2​)

المدخلات

قطبي مثل 10∠30 (بالدرجات) أو ديكارتي مثل 8.66+5j.

مثال: جمع 10∠30∘10\angle 30^\circ10∠30∘ و 5∠−45∘5\angle -45^\circ5∠−45∘.
