الجدول الدوري

ابحث عن أي عنصر بالرمز أو الاسم بالعربية أو الإنجليزية أو العدد الذري، واعرض المجموعة والدورة والكتلة الذرية والكتلة block والتوزيع الإلكتروني وإلكترونات التكافؤ مع جدول دوري كامل مُظلَّل بالعنصر المختار.

المدخلات

أدخل الرمز مثل Fe أو الاسم مثل حديد أو Iron أو العدد الذري مثل 26.

مثال: الحديد Fe، Z = 26.
