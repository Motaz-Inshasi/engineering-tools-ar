حساب الأسمدة NPK

احسب كمية السماد اللازمة لتغطية احتياج عنصر واحد من N أو P2O5 أو K2O لمساحة محددة، أو صمّم خلطة DAP وMOP واليوريا لتغطية أهداف N وP وK معاً، مع عدد أكياس 50 كغ.

القوانين المستخدمة

كمية السماد لعنصر واحد
mha=Rp/100,M=mha⋅Aham_{ha} = \frac{R}{p/100},\qquad M = m_{ha}\cdot A_{ha}mha​=p/100R​,M=mha​⋅Aha​
