خطأ الحالة المستقرة

احسب خطأ الحالة المستقرة لنظام تغذية راجعة أحادية: نوع النظام وثوابت الخطأ Kp و Kv و Ka والخطأ لدخل الخطوة والمنحدر والقطع المكافئ، مع التحقق من استقرار الحلقة المغلقة أولاً.

القوانين المستخدمة

ثوابت الخطأ
Kp=lim⁡s→0G(s),Kv=lim⁡s→0sG(s),Ka=lim⁡s→0s2G(s)K_p = \lim_{s\to0}G(s),\quad K_v = \lim_{s\to0}sG(s),\quad K_a = \lim_{s\to0}s^2G(s)Kp​=s→0lim​G(s),Kv​=s→0lim​sG(s),Ka​=s→0lim​s2G(s)
الخطأ لكل دخل بسعة A
estep=A1+Kp,eramp=AKv,eparabola=AKae_{step} = \frac{A}{1+K_p},\quad e_{ramp} = \frac{A}{K_v},\quad e_{parabola} = \frac{A}{K_a}estep​=1+Kp​A​,eramp​=Kv​A​,eparabola​=Ka​A​

المدخلات

مع تغذية راجعة أحادية: T(s) = G/(1+G).

مثال: نظام من النوع 1، فخطأ الخطوة صفر وخطأ المنحدر 1/Kv1/K_v1/Kv​.
