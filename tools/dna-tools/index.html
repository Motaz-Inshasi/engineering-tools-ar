أدوات DNA و RNA

حلّل تسلسل DNA أو RNA: السلسلة المتممة والمتممة المعكوسة، والنسخ إلى mRNA، والترجمة إلى بروتين بجدول الشيفرة الوراثية، ونسبة GC ودرجة الانصهار التقريبية.

القوانين المستخدمة

نسبة GC
%GC=G+CN×100\%GC = \frac{G + C}{N} \times 100%GC=NG+C​×100
درجة الانصهار التقريبية
Tm=2(A+T)+4(G+C)  (N<14),Tm=64.9+41 G+C−16.4NT_m = 2(A+T) + 4(G+C)\ \ (N < 14),\qquad T_m = 64.9 + 41\,\frac{G + C - 16.4}{N}Tm​=2(A+T)+4(G+C)  (N<14),Tm​=64.9+41NG+C−16.4​

المدخلات

حروف A و T (أو U) و G و C فقط. المسافات والأرقام والأسطر تُتجاهل.

مثال: جين قصير يبدأ بـ ATG وينتهي بكودون توقف.
