تمثيل الأعداد العشرية IEEE-754

حوّل أي عدد عشري إلى تمثيله بمعيار IEEE-754 بدقة مفردة (32 بت) أو مزدوجة (64 بت): بت الإشارة والأس المنحاز والجزء الكسري والقيمة الست عشرية، والقيمة المخزنة فعلاً وخطأ التقريب، والعكس.

القوانين المستخدمة

قيمة العدد الطبيعي
x=(−1)s×1.f×2e−bias,bias=127 (32), 1023 (64)x = (-1)^s \times 1.f \times 2^{e - \text{bias}},\qquad \text{bias} = 127\ (32),\ 1023\ (64)x=(−1)s×1.f×2e−bias,bias=127 (32), 1023 (64)

المدخلات

مثل 0.1 أو -6.75 أو 1e-40 أو inf أو nan.
8 خانات ست عشرية للدقة المفردة أو 16 للمزدوجة، مثل 3DCCCCCD.

مثال: تمثيل −6.75 بدقة مفردة.
