الانحدار الخطي والارتباط

أوجد خط أفضل مطابقة بطريقة المربعات الصغرى لبيانات (x, y)، مع معامل الارتباط r ومعامل التحديد R² واختبار دلالة الميل والتنبؤ، ونماذج أسية وقوى ولوغاريتمية، والرسم.

القوانين المستخدمة

معامل الارتباط
r=SxySxxSyy,t=bSEb,  df=n−2r = \frac{S_{xy}}{\sqrt{S_{xx} S_{yy}}},\qquad t = \frac{b}{SE_b},\ \ df = n - 2r=Sxx​Syy​​Sxy​​,t=SEb​b​,  df=n−2

المدخلات

سطر لكل نقطة: x ثم y بينهما مسافة أو فاصلة.

مثال من كتب الإحصاء: خمس نقاط ونتنبأ بقيمة y عند x = 6.
