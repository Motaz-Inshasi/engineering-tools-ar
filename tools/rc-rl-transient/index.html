الاستجابة الزمنية RC و RL

الاستجابة العابرة لدوائر RC و RL عند الشحن أو التفريغ: الثابت الزمني والمعادلة الزمنية للجهد والتيار والقيمة عند أي لحظة والزمن اللازم للوصول إلى نسبة معينة، مع الرسم.

القوانين المستخدمة

الثابت الزمني
τRC=RC,τRL=LR\tau_{RC} = RC,\qquad \tau_{RL} = \frac{L}{R}τRC​=RC,τRL​=RL​
الصيغة العامة لأي متغير في دائرة رتبة أولى
x(t)=x(∞)+[x(0)−x(∞)]e−t/τx(t) = x(\infty) + \left[x(0) - x(\infty)\right]e^{-t/\tau}x(t)=x(∞)+[x(0)−x(∞)]e−t/τ
