أقطاب وأصفار دالة التحويل

حلّل دالة التحويل H(s): الأقطاب والأصفار والكسب الساكن ونوع النظام والاستقرار ومعامل الإخماد والتردد الطبيعي لكل زوج أقطاب مركب، مع مخطط الأقطاب والأصفار.

القوانين المستخدمة

الصيغة المحللة
H(s)=K(s−z1)(s−z2)⋯(s−p1)(s−p2)⋯H(s) = K\frac{(s - z_1)(s - z_2)\cdots}{(s - p_1)(s - p_2)\cdots}H(s)=K(s−p1​)(s−p2​)⋯(s−z1​)(s−z2​)⋯​

المدخلات

اكتبها كسراً في s، مثل (s+1)/(s^2+2s+5). يمكن كتابة البسط والمقام محللين.
