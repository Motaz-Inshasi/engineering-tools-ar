حاسبة النهايات

احسب نهاية دالة عند نقطة أو عند اللانهاية: بالتعويض المباشر، أو بقاعدة لوبيتال للصيغ غير المحددة، أو بتقدير عددي من الجهتين مع جدول اقتراب.

القوانين المستخدمة

قاعدة لوبيتال للصيغة 0/0 أو ∞/∞
lim⁡x→af(x)g(x)=lim⁡x→af′(x)g′(x)\lim_{x\to a}\frac{f(x)}{g(x)} = \lim_{x\to a}\frac{f'(x)}{g'(x)}x→alim​g(x)f(x)​=x→alim​g′(x)f′(x)​
وجود النهاية
lim⁡x→af(x)=L  ⟺  lim⁡x→a−f(x)=lim⁡x→a+f(x)=L\lim_{x\to a} f(x) = L \iff \lim_{x\to a^-} f(x) = \lim_{x\to a^+} f(x) = Lx→alim​f(x)=L⟺x→a−lim​f(x)=x→a+lim​f(x)=L

المدخلات

اكتب inf للانهاية الموجبة أو -inf للسالبة.
