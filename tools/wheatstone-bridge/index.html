قنطرة ويتستون

قنطرة ويتستون: جهد الخرج وشرط الاتزان، وحساب المقاومة المجهولة عند الاتزان، وتيار الجلفانومتر بمكافئ ثيفينين عند إدخال مقاومته.

القوانين المستخدمة

جهد الخرج (R1 فوق R2 يساراً، R3 فوق R4 يميناً)
Vout=Vs(R2R1+R2−R4R3+R4)V_{out} = V_s\left(\frac{R_2}{R_1 + R_2} - \frac{R_4}{R_3 + R_4}\right)Vout​=Vs​(R1​+R2​R2​​−R3​+R4​R4​​)
شرط الاتزان
R1R2=R3R4  ⇒  R4=R3R2R1\frac{R_1}{R_2} = \frac{R_3}{R_4} \;\Rightarrow\; R_4 = R_3\frac{R_2}{R_1}R2​R1​​=R4​R3​​⇒R4​=R3​R1​R2​​

المدخلات

مثال: قنطرة متزنة تقريباً، R4 أكبر بـ 10%.
