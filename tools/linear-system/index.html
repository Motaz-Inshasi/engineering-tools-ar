حل أنظمة المعادلات الخطية

حل نظام معادلات خطية بأي عدد من المجاهيل بطريقة حذف غاوس-جوردان، مع عرض كل عملية على الصفوف وتصنيف النظام (حل وحيد، لا حل، عدد لا نهائي من الحلول).

القوانين المستخدمة

الصيغة المصفوفية والمصفوفة الموسعة
Ax=b  ⇒  [A ∣ b]→row ops[I ∣ x]A\mathbf{x} = \mathbf{b} \;\Rightarrow\; [A\,|\,\mathbf{b}] \xrightarrow{\text{row ops}} [I\,|\,\mathbf{x}]Ax=b⇒[A∣b]row ops​[I∣x]
شرط الحل (روشيه-كابيلي)
rank⁡(A)=rank⁡([A∣b])=n⇒unique solution\operatorname{rank}(A) = \operatorname{rank}([A|\mathbf{b}]) = n \Rightarrow \text{unique solution}rank(A)=rank([A∣b])=n⇒unique solution

المدخلات

كل سطر معادلة واحدة: معاملات المجاهيل ثم الثابت في آخر السطر. افصل بمسافة أو فاصلة.

مثال: 2x1+x2−x3=82x_1 + x_2 - x_3 = 82x1​+x2​−x3​=8، −3x1−x2+2x3=−11-3x_1 - x_2 + 2x_3 = -11−3x1​−x2​+2x3​=−11، −2x1+x2+2x3=−3-2x_1 + x_2 + 2x_3 = -3−2x1​+x2​+2x3​=−3.
