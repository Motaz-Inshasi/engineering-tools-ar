حاسبة PWM والسيرفو

حاسبة PWM للمتحكمات الدقيقة: قيمة TOP للمؤقت والتردد الفعلي ودقة PWM بالبت وقيمة المقارنة لأي دورة عمل، وحساب عرض نبضة السيرفو وقيمة المقارنة لأي زاوية.

القوانين المستخدمة

تردد PWM للمؤقت (Fast PWM)
fPWM=fclkNpre(TOP+1),resolution=log⁡2(TOP+1) bitsf_{PWM} = \frac{f_{clk}}{N_{pre}(TOP + 1)},\qquad \text{resolution} = \log_2(TOP + 1)\ \text{bits}fPWM​=Npre​(TOP+1)fclk​​,resolution=log2​(TOP+1) bits
السيرفو: عرض النبضة خطي مع الزاوية
tp=tmin+θθmax(tmax−tmin),D=tpTt_p = t_{min} + \frac{\theta}{\theta_{max}}(t_{max} - t_{min}),\qquad D = \frac{t_p}{T}tp​=tmin​+θmax​θ​(tmax​−tmin​),D=Ttp​​

المدخلات

مثال: سيرفو 180° على مؤقت 16 MHz بمقسم 8 وتردد 50 Hz.
