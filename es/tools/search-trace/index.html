Seguimiento de búsqueda lineal y binaria

Traza paso a paso la búsqueda lineal y la binaria en una lista de números: muestra la posición del valor si existe, el número de comparaciones y el máximo posible para el tamaño de la lista.

📘 Fórmula utilizada

Pulsa para mostrar
Máximo de comparaciones en la búsqueda binaria
⌊log⁡2n⌋+1\lfloor \log_2 n \rfloor + 1⌊log2​n⌋+1
Máximo de comparaciones en la búsqueda lineal
nnn

✏️ Datos de entrada

Números separados por comas o espacios. La búsqueda binaria necesita una lista ordenada; si no lo está, se ordenará primero.

Ejemplo: búsqueda binaria del 7 en una lista ordenada de siete números.
